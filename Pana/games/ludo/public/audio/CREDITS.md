# Ludo sound credits

These recordings are used as synchronized effects in Ludo. They are not
covered by the repository's code license; each retains its original terms.
The runtime ZIP is a delivery component of the game, not a reusable sound library.

| Runtime file | Source / creator | Terms |

| squish.mp3, splat.mp3 | [8 wet squish, slurp impacts — Independent.nu, submitted by qubodup](https://opengameart.org/content/8-wet-squish-slurp-impacts), impactsplat01 and impactsplat04 | [CC0](https://creativecommons.org/publicdomain/zero/1.0/) |
| swish.mp3 | [3 Melee sounds — remaxim, based on qubodup](https://opengameart.org/content/3-melee-sounds), melee sound.wav | [CC0](https://creativecommons.org/publicdomain/zero/1.0/) |

Prepared as mono 44.1 kHz MP3 at 96 kbps, with silence trimmed and peaks
limited. Playback gain and pitch vary with the action. The two Pixabay
originals were supplied by the project owner; source pages verified 2026-10-24.
